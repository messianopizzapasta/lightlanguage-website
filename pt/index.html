O que é linguagem de luz?

Linguagem de luz usa luz colorida e geometria sagrada para criar mensagens claras. Pensamento claro com intenção clara irradia para o espaço à volta — assim se forma a aura para as coisas que queres criar e manifestar no mundo. Estrutura e transforma relações, casa, lugares, pessoas, coletivos e padrões.

Grids

Um Grid é uma sequência de 7, 49 ou 144 geometrias coloridas. Uma forma só que emanas passa depressa. Um Grid fica mais tempo.

Começas com Grids de sete formas. Os pessoais são para pessoas e seres vivos, os estacionários para sítios, salas e objectos. Depois os Grids de dicionário.

Na app tens Simple 7, Simple 12, 7×7 e 12×12. Quando terminares, exportas o Grid e podes integrá-lo.
